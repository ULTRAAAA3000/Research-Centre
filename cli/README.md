# kb: интерактивная консоль Research Centre

Лёгкая кроссплатформенная утилита на Node.js для работы с базой знаний Research Centre прямо из терминала. Команда `kb` запускает собственную консоль (REPL) с приглашением `[Research-KB] > `: вы вводите запросы и флаги, утилита обращается к Cloudflare Worker, красиво показывает ответ и по завершении сохраняет лог сессии.

```text
$ kb
🔬 Research Centre KB  v1.0.0
API: https://research-centre.mrcru96.workers.dev
Команды: -s, -c, -t, -i <номер | id>, status, clear, help, exit
(на экране приветствия каждая команда подписана)

[Research-KB] > -s docker
[Research-KB] > exit
[✓] Сессия завершена. Лог сохранен в logs/kb_session_2026-10-08_12-30-05.log
```

## Возможности

- **Изолированная консоль.** Все команды обрабатываются внутри процесса Node.js и не попадают в историю `bash`, `zsh` или PowerShell (в историю оболочки попадёт только сам запуск `kb`).
- **Флаги** для поиска, разделов, фильтра по теме и открытия статьи по id.
- **Цветной вывод** (chalk), статьи с подсветкой кода в рамках и **кликабельные ссылки** на первоисточники (OSC 8).
- **Лог сессии** в `logs/`: чистый текст без цветов и escape-кодов, сохраняется при `exit`, `quit`, Ctrl+C и Ctrl+D.

## Требования

- Node.js 18 или новее (`node --version`)
- git и npm
- Linux, macOS или Windows (PowerShell, Windows Terminal, cmd)

## Установка

```bash
git clone https://github.com/ULTRAAAA3000/Research-Centre.git
cd Research-Centre/cli
npm install
npm link
```

`npm link` создаёт глобальную команду `kb`, которая ссылается на эту папку. Теперь `kb` работает из любой директории:

```bash
kb          # запустить консоль
kb start    # то же самое
kb --help   # краткая справка и выход
kb --version
```

Обновление: `git pull` в папке репозитория (ссылка из `npm link` указывает на папку, поэтому ничего переустанавливать не нужно; если изменились зависимости, выполните ещё `npm install` в `cli/`).

Удаление: `npm unlink -g research-kb-cli` (или `npm rm -g research-kb-cli`).

### Если команда `kb` не найдена

Папка глобальных команд npm должна быть в `PATH`. Посмотреть её: `npm prefix -g` (команды лежат в `bin` внутри неё на Linux и macOS, в самой папке на Windows). Добавьте её в `PATH` и откройте новый терминал.

### Windows (PowerShell)

- После `npm link` команда доступна в PowerShell, cmd и Windows Terminal.
- Если PowerShell отвечает, что выполнение сценариев отключено (запускается файл `kb.ps1`), разрешите свои сценарии один раз: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`. Либо запускайте `kb.cmd`.
- Для кликабельных ссылок и цветов используйте Windows Terminal (в старом cmd/conhost ссылки показываются как «текст (адрес)»).

## Настройка

Адрес Cloudflare Worker задан константой `API_BASE_URL` в файле [`src/config.js`](src/config.js). Менять код не обязательно: значения можно переопределить переменными окружения.

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `KB_API_URL` | адрес Worker (без слеша на конце) | `https://research-centre.mrcru96.workers.dev` |
| `KB_LOG_DIR` | папка для логов | `logs/` в папке утилиты |
| `KB_LINKS` | `on` или `off`: принудительно включить или выключить кликабельные ссылки | автоопределение |
| `KB_TIMEOUT_MS` | таймаут запроса, мс | `10000` |

Пример (Linux, macOS): `KB_API_URL=https://my-worker.example.workers.dev kb`.
Пример (PowerShell): `$env:KB_API_URL = 'https://my-worker.example.workers.dev'; kb`.

## Флаги

| Флаг | Что делает |
|---|---|
| `-s <запрос>`, `--search <запрос>` | поиск по ключевым словам: `-s docker`, `-s "zero trust"` |
| `-c`, `--categories` | список всех разделов |
| `-t <раздел>`, `--topic <раздел>` | статьи раздела: `-t security` (ключ, название или начало ключа, например `-t sec`) |
| `-i <номер или id>`, `--id <номер или id>` | полная статья: по номеру из последнего списка (`-i 3`) или по точному id (`-i wireguard-vpn`) |
| `-h`, `--help` | справка |

Правила разбора:

- Строка **без флага** считается поиском: `docker` то же, что `-s docker`.
- Значение флага это все слова до следующего флага, поэтому кавычки нужны не всегда: `-s zero trust` и `-s "zero trust"` равнозначны.
- `-t` и `-s` можно совмещать: `-t security -s ssh` ищет только внутри раздела.
- **Номер статьи** это число слева в последнем показанном списке (результаты поиска или статьи раздела). После `docker` команда `-i 2` откроет вторую статью. Список обновляется при каждом новом поиске или `-t`; без списка или с номером вне диапазона утилита подскажет, что делать. Обычный id работает как раньше.
- Приоритет, если указано несколько флагов: `-h`, `-c`, `-i`, затем `-t` и `-s`.
- Слово в кавычках никогда не считается флагом: `"-s"` будет искаться как текст.
- Неизвестный флаг или флаг без значения не ломает сессию, а выводит понятную ошибку.

## Локальные команды

| Команда | Что делает |
|---|---|
| `help` или `-h` | список флагов и команд |
| `clear` | очистить экран (`console.clear()`); накопленный буфер лога **не сбрасывается** |
| `status` | проверить подключение к Cloudflare Worker, показать время ответа и размер базы |
| `exit` или `quit` | выйти и сохранить лог сессии |

Ctrl+C и Ctrl+D (конец ввода) тоже завершают сессию с сохранением лога.

## Кликабельные ссылки

Ссылки на первоисточники выводятся через escape-последовательность OSC 8: `ESC ] 8 ; ; URL ESC \ ТЕКСТ ESC ] 8 ; ; ESC \`. Их поддерживают Windows Terminal, iTerm2, GNOME Terminal и другие терминалы на VTE, Konsole, kitty, WezTerm, VS Code. Клик (обычно с зажатым Ctrl или Cmd) открывает страницу в браузере.

Если терминал ссылки не поддерживает, утилита покажет «текст (адрес)», чтобы адрес не пропал. Принудительно включить или выключить: переменная `KB_LINKS=on|off`.

## Лог сессии

В процессе работы все запросы (с флагами) и ответы накапливаются в оперативной памяти и записываются на диск только при завершении.

- Папка: `logs/` рядом с утилитой (создаётся автоматически; не зависит от текущей директории). Своя папка: `KB_LOG_DIR`.
- Имя файла: `kb_session_YYYY-MM-DD_HH-mm-ss.log`.
- Содержимое: чистый текст без цветов и escape-кодов; кликабельные ссылки превращаются в «текст (адрес)».
- Итог: `[✓] Сессия завершена. Лог сохранен в logs/kb_session_...log`.
- Папка `logs/` добавлена в `.gitignore`, в репозиторий логи не попадают.

Фрагмент лога:

```text
[12:30:01] СИСТЕМА: Старт сессии, API: https://research-centre.mrcru96.workers.dev
[12:30:04] ВВОД   : -s docker
[12:30:04] ОТВЕТ  :
    🔎 «docker»: найдено 8
    ...
[12:30:20] СИСТЕМА: Завершение сессии (exit)
```

## Как это устроено

```text
bin/kb.js        точка входа (shebang), запуск REPL
src/app.js       цикл readline, разбор флагов, локальные команды, сигналы
src/api.js       запросы к Cloudflare Worker
src/formatter.js Markdown статей, экраны, кликабельные ссылки
src/theme.js     цветовая тема (светлые оттенки для тёмного фона)
src/logger.js    буфер сессии, очистка ANSI, запись в logs/
src/config.js    API_BASE_URL, папка логов, таймауты
test/            тесты (node --test)
```

Утилита использует JSON-API Worker (в папке репозитория `src/index.ts`):

| Запрос | Ответ |
|---|---|
| `GET /api/status` | состояние и размер базы |
| `GET /api/search?q=` | результаты поиска (до 20) с кратким описанием |
| `GET /api/categories` | разделы и число статей |
| `GET /api/topic?name=` | статьи раздела |
| `GET /api/article?id=` | полная статья: текст Markdown и источники |

История ввода: `readline` хранит стрелку-вверх только в памяти текущей сессии и ничего не пишет в файлы истории оболочки.

## Тесты

```bash
cd cli
npm test
```

Тесты проверяют разбор флагов, очистку ANSI и ссылок, имя и содержимое лога, форматирование и весь цикл REPL на подменённом API.

## Решение проблем

| Симптом | Что делать |
|---|---|
| `Не удалось подключиться ...` | проверьте адрес (`KB_API_URL`) и сеть, команда `status` покажет подробности |
| Нет цветов | терминал без поддержки ANSI или вывод перенаправлен в файл: это нормально |
| В выводе видны символы вида `]8;;` | терминал не поддерживает ссылки: `KB_LINKS=off` |
| `kb: command not found` | папка глобальных команд npm не в `PATH` (см. выше) |
| `Статья «...» не найдена` | утилита подскажет похожие id, либо найдите нужную через `-s` |
